# Pocket Window

A small study planner for the gaps between classes. Add tasks with an estimated duration, energy level, and due date. Choose how much time and energy you have to get a recommendation, then use the focus timer and mark work complete.

## Run locally

Run `npm start`, then open <http://127.0.0.1:4173>. No install or account is required. Tasks are saved in this browser with `localStorage`.

Run `npm test` to check the task matching rules.

## Features

- Add, edit, complete, and delete study tasks.
- Get a time and energy aware suggestion, with due dates considered.
- Run a focus timer and see completed time and task counts.

## AI development note

The idea, interface, code, and tests were developed with ChatGPT Codex. The prototype was tested through its task matching logic and browser interactions, then refined for usability and persistence. No personal information or API keys are included.
